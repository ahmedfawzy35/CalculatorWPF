# Calculator WPF

![Calculator WPF Banner](repo-banner.png)

A simple desktop calculator built with WPF .NET 6.

## Features
- Standard calculator interface
- History tracking
- Theme support
- Light and dark modes
- Editable calculation rows

## Technologies
- C#
- WPF
- .NET 6

## Download Release
Download the latest Windows release package here:

- [Download .zip package](https://github.com/ahmedfawzy35/CalculatorWPF/raw/main/CalculatorWPF-Release.zip)
- [Open repository](https://github.com/ahmedfawzy35/CalculatorWPF)

```bash
dotnet run
```
