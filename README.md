A modern desktop calculator built with WPF and .NET 6 for Windows.

## Overview
Calculator WPF is a lightweight desktop application for quick arithmetic operations, with support for history, theme switching, and editable calculation rows.

## Features
- Standard calculator interface
- Arithmetic history tracking
- Theme support
- Light and dark modes
- Editable result rows
- Clean WPF-based desktop UI

## Requirements
- Windows 10 or later
- .NET 6 Runtime (if running from source)

## Run from source
```bash
dotnet run
```

## Build from source
```bash
dotnet build
```

## Project structure
- `App.xaml` and `MainWindow.xaml` for UI
- `ViewModels/` for calculator logic
- `Services/` for app settings and history storage
- `Themes/` for theme resources
