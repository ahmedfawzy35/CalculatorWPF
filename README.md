# Calculator WPF

![Calculator WPF Banner](repo-banner.png)

A simple desktop calculator built with WPF .NET 6.

## Features
- Standard calculator interface
- History tracking
- Theme support
- Light and dark modes
- Editable calculation rows

## Technologies
- C#
- WPF
- .NET 6
